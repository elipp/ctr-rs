**Decisions**
- Physics/sim code lives outside Bevy (plain Rust crate, integer fixed-point, one cloneable state struct, pure `step`), Bevy only renders/inputs/networks. Loader crate stays Bevy-free. Chosen for rollback/lockstep netplay.
- GTE matches the ctr-native reference bit-for-bit, NOT real hardware (e.g. reference's MAC negative limit is -2^39, not -2^43). User was told; no objection so far. [[project-scope-online-cups]]
- Pointers in DRAM files stay payload-relative offsets (equivalent to the C patching with base 0); `DramFile::relocate(base)` reproduces the original.
- Adventure Mode is skipped; layout-chain constants like `ADVENTURE_HUB` are kept only because later BigIndex groups depend on them.

**Testing approach worth keeping**
- `crates/gte/tests/reference.rs` builds `tests/reference/reference.c` with `gcc -m32` against `reference/ctr-native` and compares all registers on seeded random streams (GTE_REFERENCE_TRIALS to scale). Skips only if reference/ is absent; fails if the C build fails. Do mutation checks in a scratch copy, never in place.
- Same style is planned for the collision port where the C is practical to drive.

**Textures (2026-10-18, viewer confirmed by user):** `loader::texture` parses `IconGroup4` texture groups (far/middle/near; 4th slot is a mosaic pointer, unsupported; viewer uses `near`), tagged pointers = `AnimTex` (`resolve_animation`, `frame_at(tick)`, 30 Hz tick), blend modes (tpage bits 5-6; 3 = opaque; STP texels blend, others opaque; viewer draws faces twice), `face_polygon`/`face_uv_order` from draw_order_low's 5-bit face fields via R226.scratchInitTable (bit 23 of the table word = horizontal UV mirror, odd rotations). Viewer: per-face vertices, atlas of (tpage,clut,kind) tiles, 4 parts (opaque/average/add/subtract via `subtract.rs` reverse-subtract), FixedUpdate 30 Hz animation, coordinate mapping is now plain scale (no axis flip; old -z mirrored the track), `--show-red` (pure (255,0,0) faces hidden by default as a heuristic; PVS doesn't hide them). Vertex colour x2 confirmed from reference (`bright = 2`).
- TODO (user agreed to defer): last texel row/column of a face is only a sliver, so tiled faces (boost pad) lose a row at seams; unknown if original does too. See TODO in crates/view/src/mesh.rs.
- Not done: mosaic/hi-res textures, culling bits (table word bit 31), `texture_low`, dithering, translucent depth ordering (game uses ordering table).

**Racer models (2026-10-18, uncommitted; user hasn't seen it yet):** `loader::model` parses CTR models (`Model::parse(DramFile)`, files `BigIndex::RACER_MODEL_{HI,MED,LOW}.nth(character)`, character order = GAME_CHARACTER_IDS: 0 crash, 1 cortex, 2 tiny, 3 coco, 4 ngin, 5 dingo, 6 polar, 7 pura, 8 pinstripe, 9 papu, 10 roo, 11 joe, 12 ntropy, 13 pen, 14 fake, 15 oxide). Hard-won facts:
- Racer textures live in **shared.vrm** (`BigIndex::SHARED_MPK_VRM` +0: rects (896,0 128x256) and (0,216 512x48)), not the level VRAM; viewer uploads both into one Vram.
- Vertices: 8-bit, frame origin `pos` added; GTE (X,Y,Z) = (b0, b2, b1) raw / read order (x, y, z) in the delta stream; `world = v * header.scale/4096 * inst.scale/4096` (driver inst scale 0xccc). numFrames bit 15 = interpolated (only every other frame stored). Delta accumulators persist across vertices within a frame.
- Commands (`DrawFunc_Normal`): bit31 new strip, bit30 reuse-first-vertex, bit26 cached vertex (no stream read), bits16-23 stack slot, bits9-15 colour idx, bits0-8 texture idx (1-based; 0 = untextured). Triangle UVs = layout uv[0..3]. No culling implemented (double-sided in viewer).
- Verified visually via a software-rendered PNG (Crash kart looks right). Viewer: `view [LEVEL] [--racer N | --no-racer]` places the neutral pose of animation 0 at driver_spawns[0]; yaw sign/forward axis from spawn.rot.y is a GUESS.
- Not done: animation playback/interpolation, instance matrix/lighting, wheels/other models, med/low LOD choice.

SlamWall and FreezeVShift states work. `Collision` (scratchpad + GTE) is part of the sim state: COLL_FIXED relies on hit_fraction/hit_radius left by COLL_MOVED. Viewer: `view LEVEL --drive [--racer N]` (crates/view/src/drive.rs: WASD/arrows, Space hop, R restart, chase cam, interpolated render).
